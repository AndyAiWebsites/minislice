How MiniSlice works

Print in four steps

  1. Add a shape or import an STL file in the Models tab.
  2. Click a model and drag its handles to move, lift, resize or turn it. Red, green and blue handles follow the X, Y and Z directions.
  3. Press Slice. The preview shows the layers. Nothing is sliced while a model is outside the plate.
  4. Press Save G-code, then import the file into your printer's app.

Pen drawing

Set Mode to Pen drawing, then import a PNG, JPEG, WebM or MP4. Pictures are traced into pen lines. Pen files never extrude filament and never heat the nozzle or bed.

Safety

Read the first layers of every print. Keep the printer in sight while it heats and prints. Temperatures and speeds are limited to safe ranges, but you should still check every value you change.
